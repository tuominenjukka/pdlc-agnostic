# Security

pdlc-agnostic is a set of prompts, schemas and small helper scripts that drive Claude Code and Claude Cowork. It runs with the permissions of the session you use it in, so treat the permissions profile it scaffolds for your project as security configuration and review it.

If you find a way the plugin could cause an agent to take an irreversible action without a human gate, leak a secret, or bypass the pre-commit guard, please report it privately rather than in a public issue. Use GitHub's private vulnerability reporting on this repository, or the email on the maintainer's GitHub profile. You will get an acknowledgement within a week.

Please do not include real secrets or customer data in a report.
