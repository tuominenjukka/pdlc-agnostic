# Code of Conduct

Be kind, be direct, assume good faith.

This project welcomes contributors regardless of background or experience. We expect everyone participating in issues, pull requests and discussions to be respectful, to keep disagreement about the work and not the person, and to accept that maintainers make the final call on what lands.

Harassment, personal attacks, and discriminatory language are not tolerated. If you experience or witness behavior that breaks these expectations, contact the maintainer privately through the email listed on the GitHub profile. Reports are handled confidentially. Consequences range from a warning to a permanent ban from the project, at the maintainer's discretion.

This document is intentionally short. If it turns out to be insufficient we will adopt the Contributor Covenant.
